# 背景方案与 ASTERIS 对照实验（2026-08-26）

状态：执行中；本文件的方案在查看本次扩大样本结果之前确定。

## 冻结方案

- 背景候选：单轮 64/5（对照）、单轮 32/1、两轮 32/1。
- 背景验证：90000002、90000003 各 8 张冻结 validation 曝光；每序列 2 次、每次 12 个随机位置，三个通量档 3000/6000/12000 DN 复用位置。合计 48 个不同位置，不把重复通量计作新位置。
- 位置一半均匀、一半靠近自动识别的亮星；真实星表不参与处理、抽样或选参数。
- 检测对象为同一论文预处理定义的输入共加图，统一使用已修复的大组检测器，不与此前原生多曝光诊断混为同一指标。
- 每个序列 4 次无源模拟，从完整 flicker→background→共加→检测链校准经验阈值。模拟包含平滑背景、独立高斯像元噪声和行偏移；误报预算为平均每图不超过 0.5。该预算仅在此简化噪声模型下成立，不是实测真实天空误报率。
- 所有背景分支采用共同的新增源资格：任一分支与已有检测重合的位置都不计入新增恢复率。
- 优选门槛：同位置、同通量的新版/旧版配对响应比值中位数在 0.95–1.05 内，恢复数较旧方案最多减少 2；先比较恢复数，再比较相对响应误差。两轮必须比新版单轮至少多恢复 2 个源才采用；没有合格新版时明确记录 `qualified=false`、`gate_winner=null`，不虚构胜出方案。绝对通量响应另行完整报告，不宣称其已校准为 1。
- 正式数据：400 帧，220 train / 80 validation / 80 test / 20 guard；保持原划分。两轮掩膜按划分隔离，禁止 test 信息进入 train 掩膜。
- 两训练分支共享新生成的图像自动配准清单、官方初始化、种子、ASTERIS8 结构和训练参数；每组最多 20 epochs、patience=6。重新训练对照，不用历史权重冒充本次同条件训练。
- 训练后在 validation 上为输入共加和网络输出重新独立校准检测阈值；test 采用不同随机种子、每序列全部 16 张 test 曝光，阈值不随 test 结果调整。
- 真实星表最终只作展示；保留 DQ，有效像元不为美观改变，科学 FITS 不作展示插值。

入口：`scripts/evaluation/run_background_ablation.py`。
实验目录：`data/processed/background_ablation_20260826/`。
旧背景 FITS、旧权重、旧评估输出均不覆盖。

### 注入结果产生前的口径澄清（20:20）

此时两个序列均仍在无源校准，没有 `truth_*.csv` 或 `source_recovery.csv`。
原先将“绝对响应 0.95–1.05”作为背景门槛不适合当前的论文输入共加：已有历史诊断表明，
裁剪/残差恢复和 PSF 测光本身会使输入共加的绝对响应偏离 1，不能全部归因于背景。
因此在查看本轮任何注入恢复结果之前，将门槛明确为“相对旧背景的额外响应变化不超过 5%”；
仍保存并最终检查绝对响应，不以相对门槛掩盖共同测光偏差。

### 完整对照的执行规则补充（20:38，第一组部分注入已完成）

初步结果出现恢复率与通量响应之间的取舍。优选门槛和已有结果不修改；但用户要求完整完成两组训练及测试，
不应把“候选没有通过我们自行设置的优选门槛”当作取消已授权对照实验的理由。
因此若所有候选均未通过门槛，仍以预先列入候选的更简单 `new32_single` 作诊断性训练分支，
同时保留失败状态、推荐旧生产默认，不称新版胜出，不通过修改阈值让其合格。
`selected` 表示进入完整对照的新版分支；是否通过验证以 `qualified` / `gate_winner` 为准。
这项执行规则是在查看部分 validation 结果后补充，不能描述为原始预注册方案；test 仍未打开或用于调整。
